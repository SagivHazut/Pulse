# Store listing copy

Paste-ready text for App Store Connect and Google Play. Every claim here was
checked against the code when it was written — if a feature changes, change
this file too, because a listing that promises something the game does not do
is a review rejection.

## Name

**Pulse Blocks - Puzzle Game** (App Store). "Pulse Blocks" alone was taken.
Use the same name on Google Play so the two listings match.

## Subtitle (App Store, 30 max)

```
Drag, drop & clear the board
```

## Promotional text (App Store, 170 max)

```
Drag, drop, clear. A calm, colorful block puzzle with power blocks, bombs and the Pulse meter. No timers, no rush — just one more run.
```

## Short description (Google Play, 80 max)

```
A calm, colorful block puzzle. Clear lines, chain combos, unleash power blocks.
```

## Description (both stores, 4000 max)

```
Pulse Blocks is a colorful block puzzle you can pick up for a minute or play for an hour.

Drag pieces onto the 8×8 board and fill a row or column to clear it. Chain clears together for combos and bigger scores. There is no timer — a run only ends when none of your three pieces will fit.

TWO WAYS TO PLAY
• Classic — just blocks, lines and combos.
• Pulse — power blocks, bombs and the Pulse meter. Clear lines to charge the meter and earn free power-ups.

POWER-UPS
• Bomb — tap a cell to blast a 3×3 area.
• Bolt — clear a whole row and column at once.
• Refresh — swap your three pieces for new ones.

MAKE IT YOURS
• Eight themes to unlock: Neon, Ocean, Candy, Galaxy, Ember, Ice, Retro and Mono.
• Four block styles: Gloss, Flat, Bevel and Outline.
• Ten achievements and a level to climb.

COME BACK DAILY
A seven-day reward cycle, with a mystery prize on day seven.

PLAY YOUR WAY
• Play offline, anywhere.
• A reduced-motion setting for a calmer board.
• Sound, music and haptics can each be turned off.

Pulse Blocks is free and supported by optional ads. Watch one to continue a run or to double a daily reward — you never have to.
```
